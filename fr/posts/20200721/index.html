Le blog version II est arrivé

2020-07-21

En bref

En général, après avoir créé un blog, il faudrait noter le processus de création ; le titre serait alors « Guide de création d’un blog Hugo ».

Mais il n’y a pas vraiment de difficulté : allez sur le site officiel de Hugo , cliquez sur QuickStart et suivez les étapes. Pour les éléments à personnaliser, si vous aimez bricoler, il suffit de consulter le code source, de le modifier et de lire la documentation.

La raison principale de cette migration est que l’ancien blog était trop laid. Comme j’ai justement changé de travail récemment, j’en profite aussi pour mettre à jour ma présentation.

Il n’y aura peut-être pas beaucoup d’articles sur le code : lorsque je rencontre un problème intéressant en programmant, je publie généralement un tweet ou j’enregistre directement le site concerné, sans le noter spécialement. Et je n’ai pas encore un niveau suffisant pour guider les autres. Mais qui sait ? Dans l’ensemble, je serai plutôt porté vers l’écriture d’autres choses.

Je ne pense pas qu’un livre d’or soit nécessaire pour le moment ; pour laisser un message, envoyer directement un e-mail est plus efficace.

Voilà pour l’instant. En attendant un nouveau blog.
