Playwright 入門

2022-01-31 Web 動化

基礎メモ

主に https://blog.logrocket.com/playwright-vs-puppeteer/ を参考にしたメモです。

Chrome が headless browser をサポートして以来 、Web 動化フレームワークは 激しく 新されています。

Puppeteer は Chrome 公式の DevTools Protocol ベースのフレームワークで、WebDriver ベースの PhantomJS より安定しています。

Playwright の開発チームは Puppeteer 出身です。Puppeteer と比べて、API は似ているため導入コストが低く、より人間的な API で複数の端末を簡単に現できます。Firefox と WebKit にも対応しますが、対応度はまだ低いです。

技術選定

Playwright、Puppeteer、Cypress、PhantomJS、Selenium（回避策は多いものの不安定）から選ぶ際は、次を考慮します。

  1. クロスブラウザ対応
  2. 長期サポート
  3. 具体的な業務に合わせた分析

業務での選択

新規プロジェクトなら Playwright を勧めます。詳しい比較は下記「その他の参考」の 2 番目の記事を参照してください。
