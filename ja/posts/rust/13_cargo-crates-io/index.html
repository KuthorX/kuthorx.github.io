カスタムコマンドで Cargo を拡張する

Cargo は本体を変更せず、新しいサブコマンドで拡張できるよう設計されています。$PATH にあるバイナリが cargo-something という名前なら、cargo something を実行して Cargo サブコマンドのように使えます。このようなカスタムコマンドは cargo --list にも表示されます。cargo install で拡張機能をインストールし、組み込みの Cargo ツールと同じように実行できるのは、Cargo の設計がもたらす非常に便利な利点です。

まとめ

Cargo と crates.io でコードを共有できることが、Rust エコシステムを多様な用途に役立てています。Rust の標準ライブラリは小さく安定していますが、crate は言語本体とは異なるペースで簡単に共有、使用、改善できます。自分に役立つコードを crates.io で共有することをためらわないでください。きっと他の誰かにも役立ちます。
