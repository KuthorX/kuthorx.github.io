Rust - Básico - 02 - Tipos de datos

2022-01-03 Rust

Tipos de datos

Comprensión

El número de bits de los tipos numéricos isize y usize depende de si el sistema se ejecuta en una arquitectura de 32 o de 64 bits

El desbordamiento de enteros provoca un panic en modo debug, pero no en modo release

Los métodos wrapping_* evitan el panic incluso en modo debug

Los métodos checked_* devuelven None cuando hay desbordamiento

Los métodos overflowing_* devuelven un booleano que indica si hubo desbordamiento

Los métodos saturating_* limitan el valor al mínimo o al máximo cuando hay desbordamiento

tuple

let tup: (i32, f64, u8) = (500, 6.4, 1);

let tup = (500, 6.4, 1);
let (x, y, z) = tup;  // asignación por desestructuración

let x: (i32, f64, u8) = (500, 6.4, 1);
let five_hundred = x.0;
let six_point_four = x.1;
let one = x.2;

array

let a = [1, 2, 3, 4, 5];
let a: [i32; 5] = [1, 2, 3, 4, 5];
let a = [0; 5];  // inicialización rápida
let a = [[0, 5]; 20];  // array bidimensional

Desbordamiento de enteros

Supongamos que tienes una variable de tipo u8 que admite valores entre 0 y 255. Si intentas darle un valor fuera de ese rango, como 256, se produce un desbordamiento de enteros. Rust tiene algunas reglas curiosas sobre este comportamiento. Al compilar en modo debug, Rust incluye comprobaciones de desbordamiento que hacen que el programa entre en panic en tiempo de ejecución si ocurre este comportamiento. Rust usa el término panicking cuando un programa termina con un error; hablaremos de los panics con más detalle en la sección «Errores irrecuperables con panic!» del capítulo 9.

Cuando compilas en modo release con la opción --release, Rust no incluye comprobaciones de desbordamiento que provoquen panics. En su lugar, si ocurre un desbordamiento, Rust realiza un wrapping de complemento a dos. En resumen, los valores mayores que el máximo que admite el tipo «dan la vuelta» hasta el mínimo de los valores que admite el tipo. En el caso de un u8, el valor 256 se convierte en 0, el valor 257 se convierte en 1, y así sucesivamente. El programa no entrará en panic, pero la variable tendrá un valor que probablemente no sea el que esperabas. Confiar en el comportamiento de wrapping del desbordamiento de enteros se considera un error.

Para tratar explícitamente la posibilidad de desbordamiento, puedes usar estas familias de métodos que la biblioteca estándar ofrece en los tipos numéricos primitivos:

  • Envolver en todos los modos con los métodos wrapping_*, como wrapping_add
  • Devolver el valor None si hay desbordamiento con los métodos checked_*
  • Devolver el valor y un booleano que indica si hubo desbordamiento con los métodos overflowing_*
  • Saturar el valor en su mínimo o máximo con los métodos saturating_*
