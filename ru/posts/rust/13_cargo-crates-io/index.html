//! `my_crate` is a collection of utilities to make performing certain

///

///
/// ```
/// let arg = 5;

Расширение Cargo собственными командами

Cargo устроен так, что его можно расширять новыми подкомандами, не изменяя сам Cargo. Если бинарник в вашем $PATH называется cargo-something, его можно запустить как подкоманду Cargo командой cargo something. Такие собственные команды также показываются при запуске cargo --list. Возможность устанавливать расширения через cargo install и запускать их так же, как встроенные инструменты Cargo, — очень удобное преимущество такого устройства Cargo!

Итог

Обмен кодом через Cargo и crates.io — часть того, что делает экосистему Rust полезной для множества разных задач. Стандартная библиотека Rust невелика и стабильна, но крейты легко публиковать, использовать и улучшать по своему графику, отличному от графика языка. Не стесняйтесь выкладывать полезный вам код на crates.io — вероятно, он будет полезен и кому-то ещё!
