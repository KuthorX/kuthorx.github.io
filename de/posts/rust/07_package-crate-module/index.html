Package Crate Module

Verständnis

Ein Package darf höchstens ein Library-Crate, aber beliebig viele Binary-Crates enthalten.

  • module pub

    mod front_of_house {
    // Andere Module, die das verschachtelte Module hier referenzieren, brauchen pub
    pub mod hosting {
        // Auch andere Module, die die fn hier referenzieren, brauchen pub
        pub fn add_to_waitlist() {}
    }

    // Auch das Referenzieren des verschachtelten struct braucht pub
    pub struct Breakfast {
        // Fields in einem struct sind standardmäßig private, externer Zugriff braucht ebenfalls pub
        pub toast: String,
        seasonal_fruit: String,
    }

    impl Breakfast {
        pub fn summer(toast: &str) -> Breakfast {
            Breakfast {
                toast: String::from(toast),
                seasonal_fruit: String::from("peaches"),
            }
        }
    }
}

pub fn eat_at_restaurant() {
    // Absolute path
    crate::front_of_house::hosting::add_to_waitlist();

    // Relative path
    front_of_house::hosting::add_to_waitlist();
}

  • module use

    // Ähnlich wie using namespace in C++
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
use crate::front_of_house::hosting;
pub fn eat_at_restaurant() {
    hosting::add_to_waitlist();
    hosting::add_to_waitlist();
    hosting::add_to_waitlist();
}

// use kann mit pub versehen werden, auch Re-exporting genannt; extern dann direkt hosting::xxx
pub use crate::front_of_house::hosting;

// use lässt sich vereinfachen
use std::cmp::Ordering;
use std::io;
use std::{cmp::Ordering, io};

// Beim Vereinfachen kann self verwendet werden
use std::io;
use std::io::Write;
use std::io::{self, Write};

// Mit * lassen sich alle Module einbinden
use std::collections::*;

Bei mod a; liest Rust die Datei oder den Ordner a im selben Verzeichnis.

Ein Package besteht aus einem oder mehreren Crates, die gemeinsam Funktionalität bereitstellen. Es enthält eine Cargo.toml-Datei, die beschreibt, wie diese Crates gebaut werden.

Für den Inhalt eines Packages gelten einige Regeln. Es darf höchstens ein Library-Crate enthalten, aber beliebig viele Binary-Crates. Mindestens ein Crate (Library oder Binary) ist erforderlich.

Separating Modules into Different Files

Bisher definierten alle Beispiele dieses Kapitels mehrere Module in einer Datei. Werden Module groß, kann man ihre Definitionen in eine eigene Datei verschieben, damit der Code leichter zu navigieren ist.

Wir verschieben beispielsweise das Modul front_of_house aus Listing 7-17 in die Datei src/front_of_house.rs, indem die Crate-Root-Datei den Code aus Listing 7-21 enthält. Hier ist die Crate-Root-Datei src/lib.rs; das Verfahren funktioniert auch bei Binary-Crates mit src/main.rs.

Dateiname: src/lib.rs


mod front_of_house;

pub use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist();
    hosting::add_to_waitlist();
    hosting::add_to_waitlist();
}

Listing 7-21: Deklaration des Moduls front_of_house, dessen Inhalt in src/front_of_house.rs steht

src/front_of_house.rs enthält die Definitionen des Moduls front_of_house, wie Listing 7-22 zeigt.

Dateiname: src/front_of_house.rs


pub mod hosting {
    pub fn add_to_waitlist() {}
}

Listing 7-22: Definitionen im Modul front_of_house in src/front_of_house.rs

Ein Semikolon nach mod front_of_house statt eines Blocks weist Rust an, den Modulinhalt aus einer gleichnamigen Datei zu laden. Für das Beispiel extrahieren wir auch hosting und lassen in src/front_of_house.rs nur dessen Deklaration stehen:

Dateiname: src/front_of_house.rs


pub mod hosting;

Anschließend erstellen wir src/front_of_house directory and a file src/front_of_house/hosting.rs to contain the definitions made in the hosting module:

Dateiname: src/front_of_house/hosting.rs


pub fn add_to_waitlist() {}

Der Modulbaum bleibt gleich, und die Funktionsaufrufe in eat_at_restaurant funktionieren ohne Änderungen, obwohl die Definitionen in verschiedenen Dateien liegen. So lassen sich wachsende Module in neue Dateien verschieben.

Beachte, dass die pub use crate::front_of_house::hosting Anweisung in src/lib.rs ebenfalls unverändert bleibt; außerdem beeinflusst use nicht, welche Dateien als Teil der Crate kompiliert werden. The mod keyword declares modules, and Rust looks in a file with the same name as the module for the code that goes into that module.
