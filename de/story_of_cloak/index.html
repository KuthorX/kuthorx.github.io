Story of Cloak · WEB-RÄTSEL

Die grünen Augen

Ein in diesem Blog verstecktes Web-Puzzlespiel

Sie spielen als Fang Li, einen Forscher. Eines Tages wachst du auf und findest dich in einer Parallelwelt im Jahr 2014 wieder.

Das Instrument in dieser Welt zeigt die Seite in diesem Blog an. Lesen Sie sie, finden Sie die Antworten und fügen Sie die Antworten wieder in die Geschichte ein.

Spiel starten Fortsetzen:

So wird gespielt

  • Hinweise finden Sie in anderen Artikeln/Videos in diesem Blog (Links werden in der Geschichte angegeben).
  • Geben Sie die Antwort in das Eingabefeld der Story ein und drücken Sie zum Absenden die Eingabetaste.
  • Falsche Antworten werden gezählt. Beantworten Sie die Frage dreimal falsch, um den ersten Hinweis freizuschalten, und kommen Sie dann der Antwort immer näher.
  • Fortschritt existiert nur in Ihrem Browser. Sie können unten auf jeder Seite auf „Diese Seite erneut abspielen“ klicken.
